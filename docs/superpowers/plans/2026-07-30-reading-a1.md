# Reading A1 Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an authored, published, server-graded, and persistently recorded A1 Reading experience across API, Admin, Web, and Shared.

**Architecture:** Add a dedicated Reading capability with normalized content and immutable attempt snapshots. API owns validation, publication, grading, idempotency, and persistence; Shared owns framework-neutral wire types; Admin and Web use their existing feature/view and authenticated resource patterns.

**Tech Stack:** TypeScript, NestJS, Prisma/PostgreSQL, Next.js 16, React Query, next-intl, Node test runner, Tailwind CSS.

## Global Constraints

- Reading is independent from Course lessons, Lesson challenges, Practice sessions, and Vocabulary progress.
- Only A1 is enabled at Admin and learner HTTP/UI boundaries.
- Passage, question, and option content is English; interface copy is English and Vietnamese.
- Learner passage detail never exposes answer correctness before submission.
- A learner submission key is idempotent; reuse with different content is a conflict.
- Attempt answer snapshots remain readable after passage edits.
- No new runtime dependency is required.
- Create and verify a versioned migration, but do not apply it to any database.
- Do not run seed, schema push, reset, provider, enrichment, or synchronization commands.

  "passage_id" INTEGER NOT NULL,
